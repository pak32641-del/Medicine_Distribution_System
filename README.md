**Medicine Distribution Management System**

A web-based Medicine Distribution Management System developed using PHP, MySQL, JavaScript, HTML, and CSS.
This project is designed to efficiently manage medicine distribution operations for both customers/users and distributors/administrators.

**Features**

User Side:
- User registration and secure authentication
- Browse available medicines
- Search medicines by name or category
- Add medicines to cart
- Place and manage orders
- View order history
- Update profile information
- Submit feedback

Distributor/Admin Side:
- Secure administrator authentication
- Manage medicine categories
- Add, update, and delete medicines
- Manage stock inventory
- Manage vendor information
- View and process customer orders
- Update order status
- Generate and maintain records
- Access dashboard analytics and reports


**Technologies Used**
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
